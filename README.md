# AI Consulting Services Landing Page 🚀

A modern, fully responsive **AI Consulting Services landing page** built with **React** and **Tailwind CSS**.  
Designed with a dark, professional UI and includes an **interactive AI Solution Recommender** to showcase real-world React logic.

---

## ✨ Features

### Core Sections
- **Hero Section** – Gradient background, animated blobs, and strong CTA
- **Services Section** – AI Consulting, Automation, Custom Development, Data & Analytics
- **Why Choose Us** – Value propositions with hover effects
- **Process Section** – Discover → Build → Scale workflow
- **Testimonials** – Client success stories
- **AI Solution Recommender** – Interactive recommendation tool (bonus feature)
- **Contact Form** – Client-side handled form with success message
- **Footer** – Clean and minimal footer

---

## ⭐ Highlight Feature (Bonus)
### AI Solution Recommender
Users select:
- Business Type (Startup / SME / Enterprise)
- Primary Goal (Automation / Growth / Cost Reduction)

The app dynamically recommends a tailored AI solution using **React state**.

This feature demonstrates:
- State management
- Conditional rendering
- Interactive UI logic

---

## 🎨 Design & UI
- **Theme**: Dark editorial design
- **Colors**: Purple & blue gradients
- **Typography**: Sora (headings) + DM Sans (body)
- **Effects**: Glassmorphism, gradients, smooth animations
- **Responsive**: Mobile, tablet, and desktop optimized
- **Accessibility**: Focus states & reduced-motion support

---

## 🛠 Tech Stack
- **React 18**
- **Tailwind CSS**
- **Vite**
- **Custom CSS animations**
